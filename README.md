# Student Academic Success & Dropout Analysis

## Overview

This project analyzes student academic success and dropout patterns using SQL and data from the UCI Machine Learning Repository.

The analysis examines demographic, academic, financial, and enrollment-related factors associated with student outcomes.

## Research Question

What student characteristics and early academic indicators are associated with student dropout?

## Dataset

The dataset contains 4,424 student records from a higher-education institution, with information covering:

- Demographics
- Academic performance
- Enrollment information
- Financial factors
- Socioeconomic characteristics

The outcome variable classifies students as:

- Graduate
- Enrolled
- Dropout

## Tools

- PostgreSQL
- SQL
- pgAdmin 4
- GitHub

## Analysis

The analysis investigates:

- First-semester academic performance
- Tuition payment status
- Age at enrollment
- Scholarship status
- Gender
- Program of study
- Application characteristics

Additional SQL analysis is used to investigate potential confounding relationships and data-quality issues.

## Limitations
